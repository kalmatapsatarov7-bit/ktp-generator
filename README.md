# KTP Generator

Веб-приложение для автоматической генерации и формирования календарно-тематического планирования (КТП).

## Возможности
- Автоматическое составление планов уроков
- Форматирование под стандартные требования
- Быстрый экспорт и подготовка документов

## Стек технологий
- Python
- Streamlit / Flask
